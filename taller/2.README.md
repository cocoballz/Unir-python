# Trabajo 2: Inventario con programación orientada a objetos

## Ejecución

Requiere Python 3, sin bibliotecas externas. Desde `taller`:

```powershell
python "2. sistema_inventario.py"
```

## Validación de los requisitos

| Punto del enunciado | Implementación |
| --- | --- |
| Constructor de `Producto` | Nombre de tipo `str` no vacío, precio numérico finito no negativo y cantidad entera no negativa. |
| `actualizar_precio()` | Valida antes de asignar; una entrada inválida conserva el precio anterior. |
| `actualizar_cantidad()` | Valida tipo entero y rango antes de asignar. |
| `calcular_valor_total()` | Devuelve precio × cantidad. |
| `__str__()` | Muestra nombre, precio, unidades y valor total. |
| Constructor de `Inventario` | Inicializa una lista vacía de productos. |
| `agregar_producto()` | Añade únicamente objetos `Producto`. |
| `buscar_producto()` | Coincidencia exacta sin distinguir mayúsculas; devuelve el objeto o `None`. Ignora espacios al inicio y al final. |
| `calcular_valor_inventario()` | Suma valores; devuelve `0.0` si está vacío. |
| `listar_productos()` | Muestra productos numerados o informa que está vacío. |
| Excepciones | Captura `ValueError`, `TypeError` y `LookupError`; permite finalizar por interrupción o cierre de entrada. |
| Menú y punto de entrada | Cinco opciones en un bucle; `__main__` crea el inventario y llama a `menu_principal(inventario)`. |

## Uso y ejemplo

El menú permite agregar, buscar, listar, calcular el total y salir. Introduce precios con punto decimal y cantidades enteras. Un Cuaderno de precio `2.5` y cantidad `4` vale `10.00`; al actualizar precio a `3` y cantidad a `5`, vale `15.00`. Un Lápiz de precio `1` y cantidad `2` eleva el inventario a `17.00`.

Los métodos de actualización se utilizan directamente sobre los objetos; el menú conserva las cinco opciones solicitadas. Los nombres duplicados se permiten y la búsqueda devuelve la primera coincidencia. Los datos se almacenan en memoria y se pierden al cerrar el programa.

Para entregar, puedes renombrar el archivo a `sistema_inventario.py`; el prefijo solo organiza el repositorio.

## Verificación

`validar_taller.py` comprueba constructores, actualizaciones, conservación de valores ante errores, tipos incorrectos, valores no finitos, búsqueda exacta e insensible a mayúsculas, totales, inventario vacío y recorrido del menú con errores y productos no encontrados.
