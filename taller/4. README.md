# Trabajo 4: Visualización con Matplotlib y Seaborn

El programa `4. visualizacion_superstore.py`, ubicado en `taller`, analiza el archivo original `4.superstore_dataset2012.csv`. También admite el nombre `superstore_dataset2012.csv` de la plataforma.

## Ejecución

Desde la carpeta `taller`:

```powershell
python -m pip install -r "4. requirements.txt"
python "4. visualizacion_superstore.py"
```

Las rutas se construyen a partir de la ubicación del script, por lo que no dependen de la carpeta desde la que lo ejecutes. El programa imprime la exploración y las conclusiones, y guarda imágenes sin necesidad de abrir ventanas.

## Preparación de los datos

Se inspeccionan dimensiones, tipos, primeros registros y valores nulos. Se convierten fechas con formato día/mes/año y campos numéricos; se eliminan filas inválidas solo en las columnas necesarias. Se comprueban cantidades, descuentos, precios, costes y orden de las fechas. Los beneficios negativos se conservan, pues representan pérdidas. No se eliminan filas por códigos postales ausentes ni se modifica el CSV.

## Visualizaciones

| Gráfico | Biblioteca | Propósito |
| --- | --- | --- |
| Histograma de ventas | Matplotlib | Analizar la distribución de importes y comparar mediana y media. |
| Boxplot de beneficio por categoría | Seaborn | Comparar dispersión, medianas y valores extremos. |
| Dispersión de ventas y beneficio | Matplotlib | Examinar su relación e identificar ventas con pérdidas. |
| Línea de ventas mensuales | Matplotlib | Observar la evolución en el período disponible. |
| Barras por categoría y segmento | Seaborn | Comparar ventas totales entre grupos. |
| Heatmap de correlaciones | Seaborn | Relacionar ventas, beneficios, cantidades, descuentos y costes de envío. |
| Matriz de correlaciones | Matplotlib | Visualización multivariante con `imshow()`, anotaciones y barra de color. |

El panel reúne los seis gráficos en subplots de dos filas y tres columnas, con título general, títulos individuales, ejes, leyendas y paletas de colores.

## Resultados guardados

En `resultados_trabajo4` se generan:

- `panel_superstore.png`: panel completo de seis visualizaciones.
- `correlaciones_superstore.png`: heatmap independiente.
- `correlaciones_matplotlib.png`: matriz multivariante de Matplotlib.
- `conclusiones.txt`: cifras y conclusiones calculadas sobre los datos.

El código incluye comentarios que explican la interpretación de cada gráfico. Las conclusiones distinguen asociación de causalidad y advierten que los meses extremos pueden estar incompletos. La moneda no está indicada en el CSV.
